# ![[Using Classes]](./assets/tktk-hero.png)

## About

In this module students will be introduced/take a deeper dive into JavaScript's built-in classes. Students will also create a basic application using the `Audio` class and some of its methods.

## Prerequisites

- Introduction to JavaScript
- Introduction to JavaScript Functions
- Introduction to JavaScript Objects
- Introduction to HTML
- Introduction to the DOM
- DOM Events
